# APIForge

APIForge is a lightweight API testing platform built with Node.js and Express. It provides endpoints and services to execute and validate HTTP API requests efficiently.

## Features
- **Controllers & Services**: Modular API execution logic.
- **Middleware**: Error handling and request validation.
- **Routes & Validators**: Input validation and structured routing for API endpoints.

## Getting Started

```bash
# Install dependencies
npm install

# Run dev server
npm run dev
```
